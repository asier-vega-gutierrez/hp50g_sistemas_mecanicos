#Como se obtubo el codigo del prograba de barras?
En la web (https://www.hpcalc.org/hp49/programming/libs/) se publico una utilidad (libEx 4.2, hay una copia en ./import/LE42.BIN) que permite obtner una codigo primitibo de un libreria intalada. De aqui se extrajo el archvio ./import/import.hpe el cual es editable. Con codigo primitibo se refiere a que es una version importada por lo que como se puede observar el archivo ./import/import.hpe no conserva la indetaciones, los intros y los comentarios originales, pero mantiene la funcionalidad y es editable. Por lo que se peude mantener a futuro, se ha hecho ya algo de limpieza.
